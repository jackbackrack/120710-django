{% comment %} "Add to calendar" for one event. Expects `event` in context. Deliberately small: on the agenda this appears on every future row, so a full-width button or a sentence of link text would swamp the thing it belongs to. An inline calendar glyph carries the meaning, with the label as the accessible name rather than visible text. Two destinations, because there is no single answer. Google is the primary — one click, opens their calendar with the event filled in — and the .ics beside it covers Apple Calendar, Outlook and anything else that already understands the format. Both are plain links, so this works without JavaScript. The SVG is inline rather than a static file so it inherits the surrounding colour and needs no second request; the same shape is used for the calendar glyph elsewhere. {% endcomment %} Add to calendar .ics
